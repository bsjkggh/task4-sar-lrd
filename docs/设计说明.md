# 任务4 线性RD成像 —— 设计说明

Zynq-7020（正点原子 ZYNQ7020 V2，xc7z020clg400-2）+ Vivado/Vitis 2020.2

---

## 1. 任务与参考模型

参考模型为 `matlab/LRD_SAR.m`（数据 `raw_data_dsx.mat`，2048×2048 复数）。雷达参数：

| 参数 | 值 | 参数 | 值 |
| --- | --- | --- | --- |
| 载频 fc | 25 GHz | 带宽 B | 800 MHz |
| 脉宽 Tp | 3 μs | 调频率 γ | B/Tp |
| 采样率 Fs | 2.4 GHz | PRF | 1500 Hz |
| 平台高度 Z0 | 300 m | 斜视角 | 0.0283 rad |

处理链（距离-多普勒，RD）：

```
距离 FFT  →  乘以匹配滤波/运动补偿参考函数 H(fr,ii)  →  距离 IFFT
          →  方位 FFT（hamming）→  取幅度  →  成像
```

其中参考函数

```
H(fr,ii) = exp(j·π/γ·fr²) · exp(-j·4π/c·R0·fr) · exp(j·4π/c·(fc+fr)·Ra(ii))
```

- 第 1 项：距离 chirp 匹配滤波；
- 第 2 项：距离向固定线性相位（距离原点对齐）；
- 第 3 项：随方位线号 `ii` 变化的 `Ra(ii)`（雷达-目标瞬时斜距）引入的相位与**距离走动**补偿，即运动补偿 / 近似 RCMC。

注意第 3 项中 `fr` 的线性相位随 `ii` 变化，因此**每条距离线的系数都不同**——这就是本任务把复数乘法放到 FPGA 的动机：2048 点 × 2048 线 = 4 M 次复数乘，纯软件循环耗时明显。

## 2. 系统架构

```
        SD 卡 (RDRAW.BIN / COEF16.BIN, FAT32)
                 │  PS: f_read
                 ▼
        DDR  RAW[16MB]  COEF[16MB]
                 │
     ┌───────────┴───────────── PS (ARM Cortex-A9, float) ────────────┐
     │  ① 取一条距离线 → fftshift(fft(fftshift(x))) → 按列缩放 int16   │
     │  ② 把该线的 2048 个 Q15 系数经 AXI-Lite 写入 PL 系数 BRAM       │
     │  ③ 启动 AXI-DMA MM2S/S2MM：STG → PL → RES                      │
     └───────────┬───────────────────────────────────────────────────┘
                 │ AXI4-Stream 32bit {im[31:16], re[15:0]}
                 ▼
     ┌──────────────── PL (100 MHz) ────────────────┐
     │  cplx_mul.v : 4×DSP48 复数乘 + 舍入 + 饱和    │
     └───────────┬──────────────────────────────────┘
                 │ AXI4-Stream
                 ▼
        DDR  WORKA[32MB] float complex
                 │
     PS: ④ 转置 → 方位 hamming + FFT → 转置回 → 距离 hamming + IFFT → 幅度
                 ▼
        DDR  MAG[16MB] u32 → 伪彩 RGB → FRAME[800×480×3]
                 ▼
        AXI VDMA (MM2S, FreeRun) → v_axi4s_vid_out → rgb2lcd → LCD
```

要点：
- PL 只做**复数乘法**这一计算密集、结构规整的运算；FFT/IFFT、转置、开方、显示由 PS 完成，便于与 MATLAB 逐位对齐、便于调试。
- VDMA 独立 FreeRun 刷新帧缓存，CPU 只负责写像素，不参与显示时序。

## 3. 复数乘法器设计（核心）

文件：`rtl/cplx_mul.v`

### 3.1 运算与定点

```
pr = (re_in·coef_re - im_in·coef_im + 2^14) >> 15   饱和到 int16
pi = (re_in·coef_im + im_in·coef_re + 2^14) >> 15   饱和到 int16
```

- 输入 / 系数 / 输出均为 **int16**；
- 系数为 **Q15**（`round(H*32767)`，|H|=1）；
- `+2^14` 为四舍五入，`>>15` 完成 Q15 定标；
- 理论最大幅度不溢出，但仍保留饱和保护（防系数写错/异常数据）。

### 3.2 结构

| 项目 | 说明 |
| --- | --- |
| DSP 用量 | 4 个乘法器（`ac、bd、ad、bc`），映射到 4 个 DSP48E1；也可用 3 乘法（`c(a+b)` 等）结构省 1 个 DSP，但需额外预加器，本设计选 4 乘法以保证时序简单、结果直观 |
| 流水级 | 系数 BRAM 同步读 1 拍 → 数据打 1 拍对齐 → 乘法/加减 → 输出 FIFO，共 3 级 |
| 吞吐 | 100 MHz 下 1 点/时钟，一条 2048 点距离线约 20.5 μs（不含 DMA 开销） |
| 反压 | 输出 16 深度 FWFT FIFO；FIFO 满时 `pipe_stall` 冻结整条流水（含包计数器和系数地址），保证系数与数据严格对齐 |
| 包边界 | 内部按 2048 beat 自动计数并产生 `TLAST`，PS 侧无需关心 TLAST |
| 系数写入 | AXI4-Lite，地址 `0x0000~0x1FFF`（2048×32bit，8 KB），`{im[31:16], re[15:0]}` |

### 3.3 与教程章节的关系（可借鉴点）

| 教程 | 可借鉴内容 |
| --- | --- |
| 第 39 章 DDS 信号发生器 | 用相位累加器 + 查找表产生 `exp(jθ)`；若不想让 PS 逐线算系数，可在 PL 用 DDS/CORDIC 实时产生 `exp(j4π(fc+fr)Ra(ii)/c)` 的线性相位 |
| 第 52 章 高速 AD/DA 频谱仪 | FFT 前后数据流、AXI-Stream 打包与位宽处理、频谱显示映射 |
| 第 53 章 高速 AD/DA FIR 滤波 | 系数 BRAM + DSP48 乘累加的标准写法、系数由 PS 写入的 AXI-Lite 接口 |

本设计采用"PS 预算系数 + PL 定点复数乘"，因为 H 依赖 `fr` 与 `ii` 两个维度，预存 2048×2048 组系数需要 16 MB，放在 DDR 由 PS 按线搬运最省 BRAM；若要做到真正实时（每脉冲在线处理），再按第 39 章思路在 PL 生成线性相位。

## 7. 已知易错点（复现时务必注意）

1. **DDR 被清空**：FSBL/`ps7_init` 只应初始化外设，不能 memset DDR；数据必须由应用自己从 SD 读到固定地址。
2. **Cache 一致性**：PS 写 DDR 后 `Xil_DCacheFlushRange`，DMA 写回后 `Xil_DCacheInvalidateRange`，否则读到旧值。
3. **DMA 长度**：一条线固定 2048 点 / 8192 字节；S2MM 的 `TLAST` 由 IP 自动产生。
4. **系数先写后传**：必须先写完 2048 个系数再启动 DMA，否则前几个点用旧系数。
5. **fftshift 对称性**：PS 用 `fftshift(fft(fftshift(x)))`，输入/输出各搬 N/2，与 MATLAB 完全对应。
6. **hamming 定义**：MATLAB `hamming(N)` 分母为 `N-1`（2047），不是 `N`。
7. **IFFT 归一化**：`ifft` 含 `1/N`，PS 用 `inv_n = 1/N`；方位 FFT 不归一化。
8. **显示阈值**：`CLIP = 1000` 对应 `LRD_SAR.m` 的 `caxis([0 1e3])`，改阈值会整体过亮/过暗。
9. **SD 卡文件名**：FatFs 使用 8.3 短文件名（`RDRAW.BIN`、`COEF16.BIN`），FAT32 分区。
