# 任务4 线性RD成像 —— 使用说明

Zynq-7020（正点原子 ZYNQ7020 V2）+ Vivado / Vitis 2020.2

工程根目录：`D:\task4_lrd_v2`

---

```
task4_lrd_v2/
```

## 二、环境

- Vivado 2020.2：`D:\VIVADO2020.2\Vivado\2020.2`
- Vitis 2020.2：`D:\VIVADO2020.2\Vitis\2020.2`
- MATLAB（R2016b 以上，用于重新生成数据，可选）
- 板卡：正点原子 ZYNQ7020 V2，800×480 RGB LCD，SD 卡 FAT32

---

## 三、构建

### 方式 A：一键（推荐）

```
cd /d D:\task4_lrd_v2\build
build_all.bat
```

依次完成：Vivado 综合/实现/导出 XSA → Vitis 平台 + FSBL + 应用 → bootgen 生成 BOOT.BIN，
并把 `BOOT.BIN` 复制到 `sd_card\`。首次约 20 分钟。

### 方式 B：分步

```bat
:: 1) Vivado（建工程、BD、综合、实现、导出 XSA）
vivado -mode batch -source D:\task4_lrd_v2\build\build_task4.tcl ^
       -log D:\task4_lrd_v2\build\build_task4.log

:: 2) Vitis（平台 + FSBL + 应用）
xsct D:\task4_lrd_v2\build\build_vitis.tcl

:: 3) BOOT.BIN
cd /d D:\task4_lrd_v2\build
bootgen -image task4.bif -arch zynq -o ..\sd_card\BOOT.BIN -w on
```

产物：

| 文件 | 说明 |
| --- | --- |
| `sd_rd_lcd\sd_rd_lcd.runs\impl_1\system_wrapper.bit` | 比特流 |
| `task4_system.xsa` | 硬件平台（含 bit） |
| `vitis_ws\task4_app\Debug\task4_app.elf` | 应用 |
| `vitis_ws\task4_plat\export\task4_plat\sw\task4_plat\boot\fsbl.elf` | FSBL |
| `sd_card\BOOT.BIN` | 启动镜像 |

## 四、上板

1. SD 卡格式化为 **FAT32**，根目录放三个文件（8.3 短文件名）：

```
BOOT.BIN      RDRAW.BIN      COEF16.BIN
```

（`sd_card\` 目录已备好这三个文件，直接复制即可。）

2. 拨码开关设为 **SD 卡启动**，插卡上电。
3. 串口 **115200**，正常日志：

```
task4 LRD: SD -> PS range FFT -> PL complex mul -> PS azimuth FFT / range IFFT -> LCD
DMA ready (mm2s=1, s2mm=1)
SD load done (2 x 16777216 bytes)
  range line 0 / 2048
  ...
PL complex-mul self-check col0: PASS (0/2048 mismatch)
stage1 done. transpose + azimuth FFT ...
azimuth FFT done. transpose back + range IFFT ...
RD image ready. render ...
task4 LRD imaging done
```

4. LCD 显示 RD 成像结果，应与 `data\ref_task4_800x480.png` 一致（亮度按幅度线性映射，>1000 截白）。

## 五、验证

### 1) 复数乘法 IP 逐位比对（xsim）

```bat
cd /d D:\task4_lrd_v2\sim
xvlog ..\rtl\cplx_mul.v tb_cplx_mul.v
xelab tb_cplx_mul -s tb_sim
xsim tb_sim -runall
```

期望输出：

```
beats out = 2048 / 2048
mismatches= 0
tlast ok  = 1, tlast bad = 0
RESULT: PASS
```

### 2) 软件 FFT 与 MATLAB 对比

```bat
matlab -batch "cd('D:\task4_lrd_v2\matlab'); verify_c_fft"
```

期望：三处误差均 < 1e-3，打印 `RESULT: PASS`。

### 3) 板上自检

PS 计算第 0 列整数模型，与 PL 输出逐点比较，UART 打印
`PL complex-mul self-check col0: PASS (0/2048 mismatch)`。

## 七、常见问题

| 现象 | 排查 |
| --- | --- |
| LCD 全黑 | 检查 VDMA FreeRun、`v_tc` 时序、LCD 背光/排线；确认 bit 与 elf 是本次构建产物 |
| LCD 全白/全黑但串口正常 | `CLIP` 阈值与数据量级不匹配；本工程应为 1000 |
| 图像散焦（方位向拖尾） | 旋转因子常数应为 `exp(-j2π/2048)`，不是 4096 点值 |
| DMA 超时/卡死 | 确认每次 8192 字节、S2MM 与 MM2S 长度一致；DMA 复位由两个 reset 相与提供 |
| 读到旧数据 | 缺 `Xil_DCacheFlushRange` / `InvalidateRange` |
| SD 读失败 | FAT32、8.3 文件名、根目录、文件大小写 |
| 构建报 BD 错误 | 先确认 `rtl/rgb2lcd3.v`、`rtl/cplx_mul.v` 存在；脚本按自身路径推断根目录，换目录无需改脚本 |
